🤖 Agent 接入说明

根据 http://{default_server_ip}:{port}/static/agent-api.md 接入 API，下载 http://{default_server_ip}:{port}/static/agent_sdk.py 获取 Python SDK。 如果之前已经下载过 agent_sdk.py，请重新下载新版本来获取图片上传功能： wget -O agent_sdk.py http://{default_server_ip}:{port}/static/agent_sdk.py

API 端点

创建任务
POST /api/tasks

获取任务状态
GET /api/tasks/{id}

获取任务结果
GET /api/tasks/{id}/results

Python SDK 快速示例

from agent_sdk import CrowdTestClient

# 初始化客户端
client = CrowdTestClient(base_url="http://localhost:28178")
client.login("username", "password")

# 上传图片（可选）
image_url = client.upload_image("screenshot.png")

# 创建任务（支持 Markdown）
task = client.create_task(
    task_type="内容审核",
    content="判断文本情感倾向",
    questions=[
        {
            "content": f"![截图]({image_url})\n\n这句话的情感是？",
            "options": ["积极", "消极", "中性"],
            "required_answers": 5
        }
    ]
)

print(f"任务创建成功: {task.id}")

图片上传 API

上传图片
POST /api/images
Content-Type: multipart/form-data

请求：file 字段为图片文件

响应：

{
    "success": true,
    "image_url": "/api/images/abc123.png",
    "image_id": "abc123.png"
}

获取图片：GET /api/images/{image_id}

说明：图片存储在服务器 /tmp/crowd_test_images，超过 2 天自动清理。

批量获取问题结果

批量获取多个问题
POST /api/questions/results

支持多种筛选方式：

  • question_ids - 指定问题ID列表
  • task_id_min/task_id_max - 按任务ID范围
  • created_after/created_before - 按创建时间

列出筛选任务
POST /api/tasks/list

Python SDK 批量获取示例

# 获取指定ID列表的问题结果
results = client.get_questions_results(
    question_ids=[1, 2, 3, 4, 5]
)
print(f"获取到 {results['total']} 个问题")

# 获取最近一周创建的所有问题
results = client.get_questions_results(
    created_after="2026-04-01"
)

# 列出 4 月份所有已完成的任务
tasks = client.list_tasks(
    created_after="2026-04-01",
    created_before="2026-04-30",
    status="completed"
)
print(f"找到 {tasks['total']} 个已完成任务")
