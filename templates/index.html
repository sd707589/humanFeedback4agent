🤖 Agent 接入说明

根据 http://115.190.35.120:28178/static/agent-api.md 接入 API，下载 http://115.190.35.120:28178/static/agent_sdk.py 获取 Python SDK。

Python SDK 快速示例

from agent_sdk import CrowdTestClient

# 初始化客户端
client = CrowdTestClient(base_url="http://localhost:28178")

# 创建任务
task = client.create_task(
    task_type="内容审核",
    content="判断文本情感倾向",
    questions=[
        {
            "content": "这句话的情感是？",
            "options": ["积极", "消极", "中性"],
            "required_answers": 5
        }
    ]
)

print(f"任务创建成功: {task.id}")
